Notes de sites - extension Chrome

Installation
1. Décompressez ce dossier.
2. Ouvrez chrome://extensions
3. Activez le « Mode développeur » (en haut à droite).
4. Cliquez sur « Charger l'extension non empaquetée » et choisissez le dossier décompressé.
5. Épinglez l'icône (puzzle > épingle) pour la garder sous la main.

Utilisation
- Sur un site, cliquez sur l'icône : donnez une note (1 à 5 étoiles) et/ou un commentaire, puis Enregistrer (Ctrl+Entrée).
- Quand vous revenez sur un site noté, sa note s'affiche sur l'icône de l'extension (ex. 4★), sans notification.
- Dans les résultats de recherche (Google, Bing, DuckDuckGo, Brave, Ecosia, Startpage, Qwant, Yahoo, Yandex), une pastille jaune apparaît sous les résultats déjà notés. Cliquez dessus pour lire la note en entier.
- L'icône de l'extension affiche la note du site en cours (ex. 4★).
- L'onglet « Mes sites » permet de rechercher, trier, supprimer, exporter et importer vos notes (fichier JSON).

Les données restent sur votre ordinateur (chrome.storage.local). Rien n'est envoyé en ligne.
Une note enregistrée sur exemple.com s'applique aussi à blog.exemple.com.
